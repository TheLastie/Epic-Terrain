# Epic Terrain — Compatibility Support

**Русский** | [English](README.en.md)

Репозиторий поддержки сообщества для сообщений об ошибках совместимости с Epic Terrain. Также здесь размещён справочный документ по конфигурации с версиями.

## Что находится в репозитории

- Для сообщений об ошибках используйте GitHub Issues и укажите шаги воспроизведения, версии, журналы и снимки экрана.
- Для отчётов о совместимости используйте метку `Epic Terrain Compatible`.
- Справочный PDF по настройке находится в корне; файлы версий — в `version/`.

## Запуск и настройка

Создайте GitHub Issue с кратким заголовком, точными шагами воспроизведения, ожидаемым и фактическим результатом, а также версией Epic Terrain.

## Примечания

Репозиторий предназначен для сообщений о совместимости и справки по настройке; самого приложения Epic Terrain здесь нет.
